# AlphaNumerical Password Generator

**Version:** 0.0.1

A simple Python password generator that creates random alphanumerical passwords and automatically saves them to a text file.

## Features

- Generates a random alphanumerical password
- Displays the generated password in the terminal
- Saves the password to `Password.txt`

## Usage

1. Download or clone this repository.
2. Open `ClickMe.bat`.
3. The generated password will be displayed in the terminal.
4. A copy of the password will also be saved to `Password.txt`.
